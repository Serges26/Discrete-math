Запуск: 
    make all - сборка и запуск программы
    make lib - создание библиотеки iterator.a
    make test - сборка и запуск тестов
    make gcov_report - создание отчета покрытия тестами исходника 
    make leaks - проверка на утечки 
    make clean - чистка сборочных файлов






*в тестах используется библиотека <check.h>, возможно требуется дополнительная установка
